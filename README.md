## 4. SLO ба Threshold

Baseline туршилтын p95 утга 234.99 ms байсан. Үүнийг 1.5-аар үржүүлж SLO босгыг тооцсон.

```text
SLO = Baseline p95 × 1.5
SLO = 234.99 × 1.5
SLO = 352.485 ms
```

Ойролцоогоор 353 ms болгон threshold-д ашигласан.

### PASS туршилт

- p95 threshold: 353 ms
- Бодит p95: 247.99 ms
- Error rate: 0%
- Үр дүн: PASS

Бүтэн гаралт: `results/threshold-pass.txt`

### FAIL туршилт

Threshold-ийг зориудаар 1 ms болгож өөрчилж, тестийн босго давсан эсэхийг шалгасан.

- p95 threshold: 1 ms
- Бодит p95: 226.79 ms
- Error rate: 0%
- Үр дүн: FAIL буюу threshold зөрчсөн.

Энэ нь тестийн threshold шалгалт зөв ажиллаж байгааг харуулна.

Бүтэн гаралт: `results/threshold-fail.txt`

## 5. Тест ажиллуулах командууд

k6 суулгасан Ubuntu орчинд төслийн үндсэн хавтаснаас дараах командуудыг ажиллуулна.

```bash
k6 run scripts/script.js
```

```bash
k6 run --vus 5 --duration 1m scripts/script.js
k6 run --vus 30 --duration 1m scripts/script.js
k6 run --vus 100 --duration 1m scripts/script.js
```

```bash
k6 run scripts/stages.js
```

```bash
k6 run scripts/threshold.js
```

FAIL туршилт:

```bash
k6 run -e SLO_P95=1 scripts/threshold.js
```

## 6. Дүгнэлт

Энэхүү лабораторийн ажлаар k6 ашиглан веб системийн гүйцэтгэлийг хэмжиж сурлаа. Эхний 5 VU, 30 секундын туршилтаар baseline p95 утга 234.99 ms гарсан. 5, 30, 100 VU туршилтуудын үр дүнгээс хэрэглэгчийн тоо нэмэгдэхэд throughput өсөж байгааг ажигласан. 100 VU үед throughput 147.11 req/s хүрсэн бөгөөд туршилтын явцад хүсэлтийн алдаа гараагүй. 5 VU туршилтын p95 нь 344.83 ms байсан нь 30 болон 100 VU туршилтынхаас өндөр гарсан тул хариу өгөх хугацаа зөвхөн хэрэглэгчийн тооноос хамаардаггүй, сүлжээний хэлбэлзэл зэрэг хүчин зүйл нөлөөлж болохыг харуулж байна. Stages туршилтаар ачааллыг 5-аас 100 VU хүртэл өсгөж, дараа нь бууруулан нийт 6976 хүсэлтийг амжилттай гүйцэтгэсэн. Baseline p95 утгыг 1.5-аар үржүүлж 353 ms гэсэн SLO босго тогтоосон. Threshold PASS туршилтаар p95 нь босгоос бага гарсан бол FAIL туршилтаар босгыг 1 ms болгож зориудаар зөрчүүлэн шалгалтын механизм ажиллаж байгааг баталгаажуулсан. Туршилтын үр дүнгээс харахад k6 нь ачааллын түвшин болон системийн хариу өгөх хугацааны хамаарлыг бодит хэмжилтээр үнэлэхэд хэрэгтэй хэрэгсэл юм.
